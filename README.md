### Project Description
Sneeze Predictor 3000 is a client-side web application that uses machine learning (TensorFlow.js and YAMNet) to detect actual human sneezes while filtering out background noise. Once a sneeze is identified, it triggers a 5-second active session timer that counts follow-up sneezes and generates a superstitious, humorous "Gossip & Positivity Report."
### The Problem (that doesn't exist)
People sneeze all the time without knowing the "true" superstitious meaning behind it or whether someone is secretly gossiping about them.

### The Solution (that nobody asked for)
A ridiculously over-engineered app that listens to your sneezes and diagnoses whether you’re being secretly loved, talked trash about, or just hit by a dust ball.
